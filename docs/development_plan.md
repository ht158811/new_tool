# 开发计划

## 阶段 1：基础架构（已完成）

工程骨架、主窗口、导航、主题、项目创建和管理信息删除、原子 JSON、路径服务、LabelMe 模型/解析器和测试。

## 阶段 2：LabelMe 扫描引擎（已完成基础闭环）

已实现相对路径主键关联、图片探测、后台完整扫描、同数据集任务互斥、进度/取消、不可变缓存、成功提交、首次添加事务及已有数据集刷新。后续质量模块将扩展重复图片和更多异常规则。

## 阶段 3：浏览与可视化（已完成基础闭环）

已实现纯文件名列表、多选、文件名/类别过滤、完整图片适配和缩放、列表下方同宽的双向滚动信息面板、可调列表/信息高度、可调项目/数据集选择宽度、双点/四点 rectangle 与 polygon 叠加和显隐，以及单击彩色标签名修改 shape 类别并原子写回 JSON。按当前使用要求不生成或显示缩略图，也不提供宽高筛选。几何坐标拖动编辑仍不在当前范围。

## 阶段 4：质量与文件管理

八类检查、用户选择处理、配对文件操作、冲突预检、有限撤销。

## 阶段 5：数据集处理

类别管理、划分、合并/拆分和基础统计。

## 阶段 6：版本与转换

完整版本副本、恢复到新目录、转换适配器和首个目标格式。

## 阶段 7：验证与交付

Windows 10/11 测试、性能与中断测试、PyInstaller 绿色 ZIP。

## 待确认清单

1. 图像分类的图像级类别来源和映射规则。
2. 类别删除时对原始 JSON 中 shape 的处理规则。
3. 来源分组的文件名提取规则。
4. 数据集拆分规则和语义分割目标格式。
5. 跨数据集扫描的并发上限。
6. 项目“同时永久删除实际数据集”在存在共享目录/目录嵌套时的安全边界。
