# 开发计划

## 阶段 1：基础架构（本迭代）

工程骨架、主窗口、导航、主题、项目创建和管理信息删除、原子 JSON、路径服务、LabelMe 模型/解析器和测试。

## 阶段 2：LabelMe 扫描引擎

图片关联、图片探测、后台完整扫描、任务互斥、进度/取消、临时缓存、成功提交和首次添加事务。

## 阶段 3：浏览与可视化

缩略图、列表、过滤、预览及 rectangle/polygon 叠加。

## 阶段 4：质量与文件管理

八类检查、用户选择处理、配对文件操作、冲突预检、有限撤销。

## 阶段 5：数据集处理

类别管理、划分、合并/拆分和基础统计。

## 阶段 6：版本与转换

完整版本副本、恢复到新目录、转换适配器和首个目标格式。

## 阶段 7：验证与交付

Windows 10/11 测试、性能与中断测试、PyInstaller 绿色 ZIP。

## 待确认清单

1. 图像分类的图像级类别来源和映射规则。
2. 类别删除时对原始 JSON 中 shape 的处理规则。
3. 来源分组的文件名提取规则。
4. 数据集拆分规则和语义分割目标格式。
5. 跨数据集扫描的并发上限。
6. 项目“同时永久删除实际数据集”在存在共享目录/目录嵌套时的安全边界。
