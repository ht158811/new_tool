# 需求说明

## 产品定位

Dataset Manager 是 Windows 10/11 上完全离线运行的视觉数据集管理软件。它管理已经由 LabelMe 标注的数据，完成浏览、检查、清洗、文件管理、类别管理、划分、合并拆分、统计、版本保存和最终格式转换。

LabelMe 是第一阶段的输入和工作格式。添加数据集时不得提前转换为 YOLO、COCO 或 VOC；所有预处理完成后，转换器才把当前完整 LabelMe 数据集输出到新目录，且不修改源数据。

## 技术和安全约束

- Python、PySide6 Widgets、Pillow、OpenCV；管理数据与缓存使用 JSON/JSONL，不使用 SQLite。当前界面仅依赖官方 PySide6 Essentials，不引入 WebEngine。
- UI 不承担复杂文件读写或业务规则；文件操作统一经应用服务。
- 扫描必须在后台完整执行，支持进度、取消、临时结果和成功后原子提交。
- 读取和扫描不得修改原始数据。危险操作必须确认，未知配对不得联动处理，禁止自动清理。
- JSON 使用临时文件、刷盘和原子替换保证一致性。
- 使用绝对路径；失效路径保留配置并允许校验后重关联。
- 所有数据处理功能需要自动化测试；异常不得静默忽略。

## 第一阶段功能范围

1. 项目与数据集两级组织。
2. LabelMe 检测、分类、语义分割任务配置，任务解析规则相互独立。
3. 图片网格/列表、原图与 rectangle/polygon 标注预览。
4. 八类质量检查：损坏、配对缺失、孤立标注、空标注、错误标注、重复图片、图片异常、类别异常。
5. 图片和明确匹配 JSON 的复制、移动、删除、重命名及有限撤销。
6. 随机、分层、来源分组和组合划分；保持图片/JSON 配对。
7. LabelMe 数据集合并，类别按名称统一，冲突不得覆盖。
8. 类别查看、重命名、待规则确认的删除；基础统计。
9. 完整副本版本保存，恢复到新目录。
10. 可扩展的最终格式转换适配器。

## 明确排除

第一阶段不实现标注编辑、自动清理/删除/隔离、数据增强、通用图像变换、版本差异、报告导出、独立日志、自动备份、数据库或云服务。

## 当前迭代验收范围

- 工程与四层架构。
- 主窗口、导航、内容区、项目首页、深浅主题。
- 项目创建/管理信息删除、安全 JSON 存储与路径管理。
- LabelMe 完整字段保留的数据模型、解析接口、基础校验和测试。

## 当前确认的导入规则

添加数据集时只选择一个根目录。图片与 LabelMe JSON 可以混合存放在任意层级的子文件夹中；程序递归检索，并以“相对父目录 + 不含扩展名的文件名”作为配对键。典型配对为 `batch/001.jpg` 与 `batch/001.json`。为兼容已有项目，数据模型仍可读取历史的图片目录/标注目录分离配置。
