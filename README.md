# Dataset Manager

面向 Windows 的本地离线视觉数据集管理工具。当前仓库已完成基础架构和 LabelMe 完整扫描闭环：四层模块、PySide6 主窗口、主题切换、项目管理、安全 JSON 存储、路径管理、LabelMe 只读解析器、后台扫描、取消和不可变扫描缓存。

在项目首页选择项目后，只需指定 LabelMe 数据集根目录。程序递归检索所有子文件夹，并将同一相对目录下同名的图片和 JSON 自动配对，例如 `line_a/001.jpg` 对应 `line_a/001.json`。扫描期间可取消，首次添加取消不会保存数据集，刷新取消会保留上一次完整结果。

项目首页汇总图片总数、有效标注图片数和异常项。有效标注图片必须已关联 JSON 且 LabelMe 解析校验通过；旧扫描数据需刷新数据集后生成该统计。

项目首页为项目列表和数据集列表提供独立删除按钮。删除项目只移除项目管理信息；删除数据集只从所属项目移除该数据集并清理扫描缓存。两者都不会删除外部图片或 JSON，且均需要确认。

项目首页的数据集列表支持鼠标拖动上下排序，调整后的顺序会写入项目管理 JSON 并在重启后保持。添加新数据集时，如果当前已有选中的数据集，新数据集会插入到其下一行；没有选中项时追加到列表末尾。

“图片浏览”页面使用纯文件名列表，类别筛选包含“全部有效 JSON”（仅显示已关联且解析有效的标注图片），明确显示“当前图片：第几张 / 总数”，并提供上一张/下一张箭头及键盘 `A`/`D` 切换。`Q` 删除选中矩形框，`E` 删除当前 JSON，`R` 进入或退出新增矩形框模式；输入文件名时这些字母快捷键会自动停用，不影响正常输入。标签框和标签名可分别显示或隐藏。同时支持多选、文件名筛选、完整图片适配与缩放，以及 LabelMe rectangle/polygon 叠加。首次进入仍不自动展示图片，需要用户主动选择具体类别或“全部有效 JSON”。列表不加载或显示缩略图。

图片默认完整适应预览区，可通过按钮或 Ctrl+滚轮缩放；滚轮缩放以鼠标位置为中心，按钮缩放以视口中心为锚点。放大后使用滚轮和滚动条浏览。文件与标注信息位于左侧文件列表下方，与列表同宽，并通过可拖动纵向分隔条调整高度；信息支持纵向滚动及 Shift+滚轮横向滚动。项目与数据集选择宽度也可通过分隔条调整。单击图片中的彩色标签名可修改该 shape 的类别名称；确认后使用原子写入同步到对应 LabelMe JSON，未知扩展字段保持不变。rectangle 只绘制边框、不填充，同时兼容 LabelMe 标准双点和四角点写法。类别筛选索引需刷新数据集后更新。

图片浏览页支持删除当前 JSON 中选定的单个标注框，以及删除当前图片对应的整个 JSON 文件。单击矩形框选中后，可按键盘 `Q`、`Delete` 或点击“删除选中矩形框”；无需再次从列表选择 shape，但仍保留一次防误删确认。删除标注框会原子写回并保留 JSON 其他字段，删除 JSON 不会删除图片，但属于不可恢复的文件删除。操作后需刷新数据集以更新扫描缓存和类别索引。

图片浏览页还支持直接拖动现有 rectangle 整体移动；单击矩形框选中后会显示四个角点控制柄，拖动角点可调整矩形框宽高；进入“新增矩形框”模式后可在图片上按住左键拖动创建新框。移动、缩放和新增坐标都会限制在图片边界内，并通过原子写入同步到对应 LabelMe JSON；图片原本没有 JSON 时会在图片同目录安全创建标准 LabelMe JSON，已有文件绝不覆盖。新增标签后需刷新数据集以更新类别索引。

“数据预处理”页面关联首页当前选中的单个数据集，提供按行×列均匀分块裁剪、可复现的组合增强，以及目标检测 YOLO/COCO/VOC 转换。格式转换可输入验证集和测试集比例，训练集比例自动使用剩余比例，并通过随机种子稳定划分为 `train`、`val`、`test`；YOLO/VOC 分别输出对应的 `images`、`labels` 子目录，COCO 输出分组图片及 `instances_train.json`、`instances_val.json`、`instances_test.json`。分块覆盖整张原图且无重叠，LabelMe rectangle/polygon 会按各分块实际边界裁切并映射为局部坐标。裁剪和增强继续输出原图片格式与 LabelMe JSON，所有图片及其同名 JSON 平铺在结果的 `data` 文件夹中，不复刻源目录结构；仅格式转换按目标格式组织目录。直接复制的图片不经过解码或重编码，并用 SHA-256 校验字节级一致；裁剪、增强等必须重新编码的 JPEG 使用质量 100、无色度抽样，PNG/WebP/TIFF 使用无损或无压缩参数。输出名称保留原文件名，仅追加 `_r1c1`、`_a1`、`_pre`、`_post` 等最短操作标识；同名冲突才追加最短数字编号。处理范围来自完整扫描缓存，可区分有效 JSON、缺失 JSON 和损坏 JSON。除用户明确选择的“批量标签重命名”和“删除无 JSON 图片”外，其他任务只向源数据集外部目录写入独立结果和 `result_manifest.json`。

“当前处理数据集”的根目录默认使用项目中保存的数据集根目录；也可通过“浏览…”选择该根目录下的某个子目录，或选择与默认根目录处于同一父目录的同级文件夹。“默认目录”按钮可随时恢复为完整数据集根目录。子目录复用现有扫描缓存；同级目录如果已作为数据集添加则复用其缓存，否则执行一次只读临时扫描后再预览和处理。

数据预处理还提供独立的“标签分割”：用户输入分隔符，前标签输出和后标签输出分别配置，互不绑定。每套输出都可单独启用，并独立选择“前标签保留”“后标签保留”或“前后标签同时保留”，也可独立决定是否按实际保留的标签建立目录；目录名直接使用所选标签对象，不再追加哈希。Windows 禁止用于目录名的字符使用可读的下划线替换，例如 `banmian:bansun` 输出为 `banmian_bansun`。没有分隔符的标签固定保留原标签，不再提供标签置空或跳过 shape。配对图片与 JSON 同目录，图片为字节级完整复制，源数据不修改。

数据预处理新增“批量标签重命名”：输入当前标签名和修改后的标签名后，程序精确替换原始有效 LabelMe JSON 中匹配的 `shapes[].label`，无需填写输出目录，图片不会修改。执行前先校验全部目标 JSON，确认无误后再原子写回；提交失败会回滚已修改文件。完成后需要刷新数据集以更新类别索引。

数据预处理新增“删除无 JSON 图片”：仅处理扫描结果中没有关联 JSON 的图片，并直接在原数据集文件夹中删除。界面会显示预计数量并要求二次确认；执行时还会复核同名 JSON 及同目录 JSON 的 `imagePath`，防止缓存过期导致误删。候选图片会先事务性暂存，中途取消或失败会恢复原位置，全部复核完成后才永久删除。完成后需要重新扫描数据集。

“选择处理功能”区域支持鼠标拖动功能项调整显示顺序，拖动只改变界面排列，不会串联或自动执行功能。

原“数据统计”入口已替换为“模型测试”。页面支持选择已扫描的数据集、Ultralytics YOLO 检测/实例分割模型、模型输入宽高、置信度、IoU、最大目标数和运行设备。模型会逐图推理，并在原图片旁生成同名的标准 LabelMe JSON；默认跳过已有标注，也可以明确选择覆盖。任务中途取消不会写入本次预测，批量写入失败时会回滚已写文件，原图片始终不会被修改。完成后重新扫描数据集即可刷新有效标注数量和类别。

## 克隆后直接运行（Windows）

电脑只需预先安装一次 64 位 Python 3.10–3.13，推荐 Python 3.12。克隆仓库后：

1. 双击根目录的 `run.bat`。
2. 首次运行会自动在项目内创建 `.venv` 并安装依赖，需要能够访问 Python 软件包源。
3. 安装完成后软件自动启动；以后双击 `run.bat` 会直接复用环境。
4. 当 `pyproject.toml` 或 `requirements-runtime.txt` 发生变化时，启动器会自动重新同步依赖。

如果只想提前安装环境而不启动软件，可双击 `setup_environment.bat`。`.venv`、运行数据和缓存均已加入 Git 忽略列表，不会污染代码仓库。

## 环境

- Windows 10/11
- Python 3.10–3.13（界面使用精简的官方 PySide6 Essentials 组件）

## 手动安装与运行

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
dataset-manager
```

也可以运行：

```powershell
python -m dataset_manager
```
